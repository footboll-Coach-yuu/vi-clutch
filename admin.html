管理画面に接続

写真・動画の活動レポート、開催カレンダー、冬スクールの募集案内を更新できます。

更新用キーはこの画面を開いている間だけ保持し、保存しません。送信先はGitHub公式APIのみです。キーをこのチャットに送る必要はありません。

初めて使うときの設定
  1. GitHubにログインし、Fine-grained tokenの作成画面を開きます。
  2. 対象の所有者を footboll-Coach-yuu、リポジトリは「Only select repositories」から vi-clutch だけに限定します。
  3. Repository permissionsの「Contents」を「Read and write」にし、有効期限を設定してキーを作成します。その他の追加権限は不要です。
  4. 作成されたキーを上の欄に貼り付けます。キーは他人に共有せず、GitHubの設定で管理してください。

ファイルを直接開いた場合は接続できません。公開済みのHTTPS管理画面、またはローカル確認用のlocalhostで開いてください。
